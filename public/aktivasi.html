Mengatasi Kendala (FAQ)

Pilih masalah yang Anda alami di bawah ini:

Peringatan "Too Many Devices" terjadi jika profil lain sedang menonton di batas maksimal.

Jika Anda tiba-tiba ter-logout dan muncul peringatan "Incorrect Password" atau "Tidak dapat masuk".

Jika muncul layar TV meminta Update Household (Rumah Tangga Netflix) atau kendala Lokasi/VPN.

📱 HP / Tablet Android:
Buka Pengaturan HP → Aplikasi (Apps) → Netflix → Penyimpanan (Storage) → Klik Hapus Data & Hapus Cache.

🍎 iPhone / iPad (iOS):
Buka Pengaturan (Settings) HP → Scroll cari Netflix → Aktifkan tombol Reset, lalu buka ulang aplikasi Netflix.

📺 Smart TV / Android TV / STB:
Buka menu Pengaturan Aplikasi Netflix TV → Pilih Keluar (Sign Out) atau Reset, atau buka Pengaturan TV → Aplikasi → Netflix → Hapus Data & Cache.

💻 Laptop / PC Browser:
Buka link netflix.com/clearcookies atau tekan Ctrl + Shift + Delete untuk hapus cache browser.
Akun Baru Berhasil Diberikan!
Akun pengganti unik baru telah dihubungkan ke Kode Akses Anda.
Panduan Akses & Logout / Hapus Cache Perangkat:
1. Smart TV / Android TV / STB:
  • Pastikan aplikasi TV Anda sudah menampilkan 8 digit kode angka baru.
  • Cara Logout / Reset TV: Buka menu Pengaturan Aplikasi Netflix TV → Pilih Keluar (Sign Out) atau Reset. Atau buka Pengaturan TV → Aplikasi → Netflix → Hapus Data & Cache.
  • Klik "Buka Netflix Sekarang" di bawah untuk memasukkan 8 digit kode TV baru.
2. HP / Tablet Android:
  • Cara Hapus Data & Cache: Buka Pengaturan HP → Aplikasi (Apps) → Netflix → Penyimpanan (Storage) → Klik Hapus Data (Clear Data) & Hapus Cache.
  • Atau klik opsi Logout / Keluar di profil aplikasi Netflix Anda.
  • Klik "Buka Netflix Sekarang" di bawah untuk otomatis masuk akun baru.
3. iPhone / iPad (iOS):
  • Cara Reset Aplikasi: Buka Pengaturan iPhone (Settings) → Scroll cari Netflix → Aktifkan tombol Reset, lalu buka kembali aplikasi Netflix.
  • Atau Logout dari aplikasi Netflix di iPhone Anda.
  • Klik "Buka Netflix Sekarang" di bawah.
4. Laptop / PC Browser:
  • Buka link Bersihkan Cookies Netflix ini untuk menghapus sesi lama.
  • Klik "Buka Netflix Sekarang" di bawah ini.
Tips: Jika tampilan web ini belum berubah, silakan Refresh / Muat Ulang Halaman web ini lalu masukkan Kode Akses Anda kembali.
